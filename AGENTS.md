# QORVAYN Website

Next.js App Router + TypeScript + Tailwind-style CSS + Framer Motion + React Three Fiber.

## Commands
- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm run build`

## Conventions
- Server components by default; use client components only for motion, forms, or WebGL.
- Use official QORVAYN content only. Do not invent claims, team bios, product status, addresses, or metrics.
- Product visuals are conceptual and must be labeled as such.
- Team role labels should only be published with team consent and confirmed responsibilities.
- Keep routes accessible, responsive, keyboard navigable, and respectful of reduced motion.

## Boundaries
No database, auth, analytics, payment, email service, or external API is configured. Contact and email capture forms are interface-only.
